# AGENTS.md

This repository holds a GitHub profile README and its assets. It has no application code, build step or test suite.

## Layout

- `README.md`: the public profile page.
- `assets/`: images used by the README (for example `profile-banner.svg`).
- `pull_request_reviews/`: saved pull request review notes.
- `CONTEXT.md`: short orientation notes for this folder.

## Conventions

- Keep claims in the README factual and checkable against the linked repositories, including test counts and metrics.
- Reference assets with relative paths; keep image files small.

## Safety and done

- Never commit secrets, tokens or `.env` files.
- Done means the README renders on GitHub, every link and image path resolves, and the diff touches only the intended files.
